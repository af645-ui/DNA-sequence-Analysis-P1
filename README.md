# DNA-sequence-Analysis-P1
This project analyses 2nd-generation DNA sequencing reads by identifying nucleotide mismatches against a reference sequence. It looks up mutation frequencies, substitution types and their positions between control and treatment groups.

Inputs and Outputs:
The project utilises DNA sequencing reads from control and treatment samples, alongside a reference sequence. Five functions are used to validate reads, identify nucleotide mismatches, analyse individual reads, summarise samples and compare mutation positions between groups. The results include two tables for each experimental group. The first summarises valid and invalid reads, mismatch percentages, mismatch events and the three most frequently affected positions. The second presents nucleotide substitution counts and their frequencies per 100 valid reads.

The final function is not complete, but the tests were conducted regardless.
